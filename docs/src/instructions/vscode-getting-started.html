02-light-modern-theme.md
02

Switch to the Light Modern theme

VS Code opens in a dark theme by default, which can feel unfamiliar on first use. Light Modern is Microsoft's built-in light theme — bright, high-contrast, and closer to the everyday applications you already know.

Why Light Modern Bright and familiar, consistent with everyday productivity applications.
Higher contrast text and icons, for easier reading on shared screens and projectors.
Included by default — no extension required.
1

Open the Command Palette

The entry point to every command and setting in VS Code.

Ctrl+Shift+P (Windows/Linux)  ·  ⌘+Shift+P (Mac)

Alternatively, use View → Command Palette… from the menu.

2

Run "Preferences: Color Theme"

Type Color Theme and select the matching command.

>Color Theme
Preferences: Color Theme
Preferences: File Icon Theme
Preferences: Product Icon Theme
3

Select Light Modern

Use the arrow keys or mouse to preview each theme, then select the one with a bright, white editor.

4

No save required

VS Code applies the theme immediately and remembers the selection. Repeat these steps at any time to change it.

Set up your workspace

Today's labs will generate folders and files as you go. Set up one workspace now to keep everything in a single, organized location.

1

Create a root folder

Choose an easy-to-find location, such as Desktop or Documents, and name it zenika-ai-driven-discovery. This folder becomes your VS Code workspace.

2

Open it in VS Code

File → Open Folder… and select the folder.

Ctrl+KCtrl+O (Windows/Linux)  ·  ⌘+O (Mac)
Do you trust the authors of the files in this folder?

VS Code shows this prompt once per folder, as a safety check.

Yes, I trust the authorsNo, I don't trust the authors

Select Yes, I trust the authors, since this is your own folder.

3

Add folders and files as needed

Hover over the workspace name in the Explorer to reveal the toolbar, then use New Folder or New File to add items as the workshop progresses.

04-copilot-custom-agent.md
04

Build a custom Copilot agent

A custom agent is a file that defines a name, role, and set of instructions for Copilot to follow whenever it's invoked. The fastest way to create one is to have Copilot generate it with /create-agent. Requires GitHub Copilot to be signed in and enabled.

PART A · CREATE THE AGENT
1

Start a fresh chat session

Open Copilot Chat — or click New Chat if a conversation is already running — so the agent is created without leftover context from earlier prompts.

Ctrl+Alt+I (Windows/Linux)  ·  ⌘+Ctrl+I (Mac) — opens Copilot Chat
Ctrl+L (Windows/Linux)  ·  ⌘+L (Mac) — starts a new chat
2

Switch to Agent mode, in your workspace

Confirm zenika-ai-driven-discovery is open — this is where the agent file will be saved — then set the chat mode dropdown to Agent.

3

Run /create-agent with a name and scope

Enter the command in this format, then press Enter:

/create-agentScaffold a new custom agent from a description
/agentsOpen Configure Custom Agents
/clearClear the conversation
/create-agent named [agent name] that does the following: [scope of the agent]

For example:

/create-agent named lab-helper that does the following: acts as a patient coding tutor for workshop attendees, explains each step in plain language, and points to the exact file to edit.
4

Answer Copilot's follow-up questions

Copilot may ask where to save the agent or which tools to allow. Reply directly in the chat.

COPILOT CHAT · AGENT＋ New Chat
